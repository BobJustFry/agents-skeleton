# Каркас — готовая AI-команда для любого проекта

Каркас ставится в папку проекта. После этого Claude Code в этой папке работает как **Chief Orchestrator**: он понимает задачу, планирует, раздаёт работу 22 специалистам, проверяет результат и отчитывается вам.

Подходит для:
- сайтов;
- AI-контента, видео и музыки;
- продвижения;
- веб-, мобильных и десктоп-приложений;
- ботов и AI-продуктов.

Работает как в новых, так и в уже существующих проектах.

## Как пользоваться

**Новый проект.** Запустите `install.cmd` двойным щелчком и введите путь к новой папке, например `P:\Projects\МойСайт`. Папка будет создана вместе с командой.

**Существующий проект.** Сделайте то же самое, но укажите папку проекта. Ваши файлы не удаляются и не перезаписываются. Если в проекте уже есть `CLAUDE.md`, в его конец добавится одна строка подключения координатора. Если есть `.claude/settings.json`, к нему добавятся два хука, а ваши настройки сохранятся вместе с резервной копией.

**Обновить команду в проекте** после изменений в каркасе:

```powershell
P:\Projects\Каркас\install.cmd "P:\Projects\МойПроект" -Update
```

Старые версии файлов сохраняются в папке `.claude\team\backup\` внутри проекта.

После установки откройте папку проекта в Claude Code и опишите, что нужно сделать.

## Правила команды

- **Язык.** Между собой и с координатором агенты общаются на английском: это родной язык моделей Claude, на нём они работают точнее. С вами координатор общается только по-русски, и всё, что предназначено вам, пишется по-русски.
- **Свежие данные.** Перед задачей каждый специалист сверяется с официальной документацией. Сведения хранятся в `docs/knowledge/` проекта и обновляются, если им больше 7 дней.
- **Кратко, без воды.** Все отвечают по делу.
- **Если чего-то не знаем:** сначала официальная документация, потом практический опыт из интернета, и только потом вопрос вам.
- **Деньги** тратятся только в рамках бюджета, который вы утвердили на задачу целиком или на этап.
- **С вами спорят.** Если вы ошибаетесь, ни координатор, ни агенты не соглашаются. Спорное решение выполняется, только если вы подтвердили риски своим кодовым словом. Слово хранится только в ваших личных настройках `~/.claude/CLAUDE.md`, в каркасе его нет.
- **Работа не встаёт.** Пока сессия открыта, координатор раз в 5 минут проверяет, есть ли работа. Если работы нет, проверка проходит молча. Если координатор пытается остановиться при незавершённых задачах, хук возвращает его к работе.
- **Только профессиональные инструменты.** В продакшне запрещены инструменты, которые искажают видео, изображения, звук, интерфейс, тексты или код. Результат каждой обработки сравнивается с исходником.

Модель в таблице — значение по умолчанию. Под каждую задачу координатор выбирает модель и уровень усилий сам, по правилам из раздела 13 своего промта.

## Что внутри

| Путь | Что это |
|---|---|
| `template/CLAUDE.md` | точка входа проекта, подключает координатора |
| `template/.claude/team/ORCHESTRATOR.md` | промт координатора: роль, команда, правила, политика моделей (раздел 13) |
| `template/.claude/agents/` | 22 промта агентов |
| `template/.claude/team/templates/` | шаблоны документов проекта и базы знаний |
| `template/.claude/team/hooks/`, `template/.claude/settings.json` | механизм непрерывной работы: пульс и защита от остановки |
| `install.cmd`, `install.ps1` | установка и обновление |

## Пересмотр моделей

Каждый день в 12:00 и 18:00 запланированная задача «Пересмотр моделей команды (Каркас)» сверяет раздел 13 промта координатора с актуальной линейкой моделей Claude. Если что-то изменилось, она обновляет этот раздел. Задача работает, пока открыто приложение Claude.
