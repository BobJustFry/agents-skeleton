# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/). Версия: `0.1.<число коммитов>`.

## [0.1.18] - 2026-10-15
### Добавлено
- Защита платных вызовов в три уровня. Повод — инцидент в проекте Vupen VPN: агенту поручили платную генерацию с пометкой «документацию изучать не нужно».
  - **Агенты.** Поле `FRESHNESS` в задании больше не отменяет обязанность изучить официальную документацию. Отклонение от задания агент отмечает в отчёте.
  - **Координатор.** `FRESHNESS` обязательно. `n/a` допустимо только для локальных задач и с причиной. Для платных генераций задание прямо запрещает платные вызовы до появления записи в базе знаний.
  - **Хук `paid-guard`.** Перед вызовом PreToolUse блокирует платные MCP-инструменты без свежей (не старше 7 дней) записи в `docs/knowledge/` с полем `Covers:`, покрывающим инструмент и модель. Бесплатные вызовы не блокируются. Разрешённые платные вызовы пишутся в `.claude/team/state/paid-calls.log`. Настройки: `.claude/team/paid-tools.json` и `paid-tools.local.json` для своих инструментов проекта.
- Поле `Covers:` в шаблоне записи базы знаний.
- Тесты `tests/paid_guard_test.py`.

### Известные ограничения
- Платные вызовы API из кода программы (у `ai-engineer`) хук не видит. Там действует правило в промте и бюджет.
- Документация Claude Code не говорит явно, действует ли блокировка хуком в режиме обхода разрешений. Требуется проверка вживую.
